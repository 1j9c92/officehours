# OfficeHours

A mentorship marketplace connecting mid-career and senior tech professionals with early-career people and career pivoters.

**Stack:** React + Vite + Tailwind CSS · Supabase · Stripe Connect · Google Meet · Claude API · Vercel

## Status

🚧 In design/planning phase

## Sub-projects

1. Foundation — auth, profiles, database schema ← current
2. Mentor Onboarding — LinkedIn signup, pricing tiers, admin approval
3. AI Intake — adaptive mentee diagnostic via Claude API
4. Browse & Match — mentor directory with filters
5. Booking & Payments — calendar, Stripe Connect, Google Meet
6. Post-Session — AI-generated notes and action items
